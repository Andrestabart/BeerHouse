# BeerHouse

Simple FastAPI app for handling orders in a gastro bar.

## Requisitos

Instalar dependencias:

```bash
pip install -r requirements.txt
```

## Uso

Ejecuta el servidor con:

```bash
uvicorn app:app --reload
```

Luego podrás acceder a la documentación automática en [http://localhost:8000/docs](http://localhost:8000/docs).
